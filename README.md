# 숙면용사 Backend

숙면용사는 **재미있는 경험을 통해 수면시간을 자연스럽게 늘리는 게임형 수면 코치 앱** 입니다.

이 저장소는 숙면용사의 **백엔드 개발을 담당하는 레포지토리**입니다.

---
## ⚙️ 기술 스택
- Java 21
- Spring 4.0.1
- Spring Security
- Swagger 2.7.0
- MySQL 8.0
- Redis
- AWS EC2
---
## 🏗️ 프로젝트 구조
- 도메인 주도 설계 (DDD)
- main 중심 브랜치 구조: main은 배포 브랜치, 각자 개발 후 해당 브랜치로 머지
- 브랜치명은 [닉네임]/[커밋 메시지 컨벤션]/[설명] 으로 통일
- 새로운 기능은 Feat/, 리팩토링은 Refactor/, 핫픽스는 Fix/ 등등


## 📋커밋 컨벤션
| Message  | 설명                                              |
| :------: | :------------------------------------------------ |
|   feat   | 새로운 기능 추가                            |
|  fix   | 버그 수정 |
|  refactor  | 코드 리펙토링 |
| comment | 주석 추가 및 변경                                     |
|  rename   | 파일 혹은 폴더명 수정                |
|  remove   | 파일 혹은 폴더 삭제                |
|  chore   | 기타 변경사항                |
 | docs   | 문서 추가, 수정, 삭제   |

---
## 👤 담당 도메인
- 루이/최종건: 회원 정보 담당
- 이안/유용선: 캐릭터 담당
- 제로/박준영: 수면 기록 담당
- 짭상혁/김상혁: 로그인 & 보안 담당
---

## 환경 변수
  | Message  | 설명                                              |
  | :------: | :------------------------------------------------ |
  |   DB_URL   | 데이터베이스 url                            |
  |  DB_USER   | 데이터베이스 유저(root) |
  |  DB_PASSWORD  | 데이터베이스 패스워드 |
  |  JWT_SECRET   | JWT 토큰 생성 암호  |
  |  OPENAI_API_KEY   | OpenAI API Key  |

---
## 🛜 인프라 구성도

- 빠른 개발과 배포를 위해 단일 EC2 위에 백엔드 서버, mysql, redis가 올라가있는 모놀리식 구조
- CI/CD 파이프라인으로 메인브랜치로 push시 배포 자동화
